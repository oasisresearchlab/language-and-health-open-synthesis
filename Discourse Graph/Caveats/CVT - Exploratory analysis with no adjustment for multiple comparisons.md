## Limitation

The analysis was exploratory and the type I error was not adjusted for multiple comparisons, so the many reported p-values should be interpreted cautiously and some significant associations may be chance findings. The authors argue the number of significant associations exceeds what chance alone would produce, but the secondary adjusted predictors (age, years in the US, insurance) in particular should be read as hypothesis-generating rather than confirmatory.

## Supporting Quote

> "Because this is an exploratory analysis, we did not adjust the type I error to account for multiple comparisons; thus, the p-values should be interpreted cautiously. However, the number of significant associations (p < .05) found in these analyses is much greater than would be expected by chance if there were no associations in the data." (Krankl, 2011, p. 85)
