# Skill — Templates & grounding

Canonical insert-templates: `utils/templates/T - *.md` (used by the Discourse Graphs plugin on node
creation). This file documents how to fill each and the grounding/audit rules. Frontmatter ids:
`nodeTypeId` (CLAUDE.md table) + `nodeInstanceId` (UUIDv7). Every synthesis template also seeds
`curationStatus: Initial AI draft` (human-AI review axis — only the human advances it; see Skill-references).

## EVD — Evidence (`T - Evidence`)

Frontmatter: `NodeType: Evidence`, `Source: [[@<citekey>]]`, `tags:` (domain facets + one
`epistemic/*`), and the mirrored fields `languageConcordanceFactor` / `healthOutcome` /
`deliveryContext`.

- **## Description** — 2–4 plain sentences with the number(s) and a `(Fig. N)` / `(Table N)` ref.
  **Embed the grounding figure/table FIRST** (becomes the keyImage), then verbatim quote(s) + page.
- **## Methods Context** — the inverted **What** (observable) / **How** (design+procedure, link
  `[[ART]]`) / **Who** (equivalence class). Each block: one-line summary + verbatim quote + quote-crop.
- **## Other Notes** — optional metrics table / commentary.
- Edges: authored from CLM/EP (Supporting/Contradicting Evidence) and CVT (Qualifies) — not here.

## CLM — Claim (`T - Claim`)

Frontmatter: facets + one `epistemic/*`, optional `TruthValue`.
- **## Supporting Evidence** / **## Contradicting Evidence** — `[[EVD - …]]` bullets (→ EVD→CLM
  supports/opposes). Verify each is statement-level, not mere paper overlap.
- A CLM may aggregate EVDs from many papers.

## QUE — Question (`T - Question`)

- **## Key Papers Asking This Question** — `[[@citekey]]`.
- **## Claims addressing this question** — nested `[[CLM]]` → `[[EVD]]` (→ CLM→QUE informs).
- Quote rule: any QUE quote must be the paper's question/aim/objective — never methods or results.

## CVT — Caveat (`T - Caveat`)

Frontmatter: `type: author-stated|inferred`, `severity: low|moderate|high`.
- **## Source** `[[@citekey]]`; **## Limitation**; **## Supporting Quote** (verbatim + crop; add
  `[Inferred: …]` when inferred); **## Qualifies** — `[[EVD]]` bullets (→ CVT→EVD qualifies).

## ART — Artifact (`T - Artifact`)

A concrete system/intervention (e.g., *video-interpreting tablet-on-wheels*, *bedside phone-app
interpreting*, a bilingual-provider program). Purpose / Mechanism / Example(s). EVD **How** fields link
here. May carry domain facets.

## PTN — Pattern (`T - Pattern`)

Conceptual class over ARTs (e.g., "direct-access interpreting"). Light use; defer unless a concept
layer is needed.

## Grounding rules

- **Figures/tables** come from our extractors: `data/figures/<citekey>/` (Route A, OA XML — highest
  fidelity) or `data/figures_pdf/<citekey>/` (Route B, PDF parse). `ground_figures.py` matches an
  EVD's `(Fig N)`/`(Table N)` ref and embeds it first; copies the asset into `attachments/`.
- **Quote crops** are auto-generated by `quote_pipeline.py` with per-type highlight colors and
  canonical names. Author prose + verbatim quote only; do not hand-place crop embeds.
- **One quote → one PNG filename** (no reuse across different quotes).

## Reporting standard

~~TRIPOD-LLM~~ is **not** used. If a per-paper reporting summary is wanted, keep it minimal and on the
**source page** only, using a health-appropriate standard (STROBE / CONSORT / PRISMA) — optional, not
required for promotion.

## Audits (gate promotion)

- `verbatim_audit.py` — quote ↔ PDF (NFKD+alnum); fix <50% matches before promoting.
- `attachment_audit.py` — CVT qualifies EVD only; every EVD→(CLM & QUE); every CLM→QUE; every EP has
  ≥2 EVD→EP edges from ≥2 distinct papers.
- `readability_pass.py` — mechanical formatting (blank lines after headings, blockquote separators).
