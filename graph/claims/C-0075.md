# C-0075 — Transitioning from paper to electronic consent improves documentation of language-concordant interpreter-mediated surgical consent for LEP patients

Transitioning from paper consent forms to an EHR-integrated electronic consent (eConsent) that requires interpreter documentation improves the documentation of language-concordant, interpreter-mediated surgical informed consent for patients with limited English proficiency.
