# C-0123 — LEP surgical populations are linguistically diverse with need concentrated in a few dominant languages and a long tail

LEP patients presenting for surgical and procedural care are linguistically diverse, spanning many primary languages, but interpretive need is concentrated in a small number of dominant languages with a long tail of rarer ones — a distribution that shapes which languages can be feasibly staffed with in-person interpreters.
