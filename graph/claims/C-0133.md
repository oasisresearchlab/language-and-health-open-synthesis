# C-0133 — Unsupervised machine translation of medical information into low-resource languages introduces more meaning-changing errors than professional translation

Unsupervised machine translation of written medical information into low-resource languages (e.g. Bengali) introduces more critical, meaning-changing errors than professional human translation.
