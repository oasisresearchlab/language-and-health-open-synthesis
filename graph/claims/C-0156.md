# C-0156 — Physician lack of knowledge about interpreter value and use is a leading modifiable risk factor for unsafe reliance on own language skills

Physicians' lack of knowledge about the value of using trained interpreters and how to work with them effectively is a leading, highly modifiable risk factor that drives partially bilingual physicians to rely on their own limited language skills instead of calling an interpreter.
