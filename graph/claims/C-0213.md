# C-0213 — Healthcare staff find mobile translation apps a useful and acceptable tool for basic communication with LEP patients when an interpreter is unavailable

Healthcare staff find mobile translation apps a useful and acceptable tool for basic, low-risk communication with limited-English-proficiency patients when a professional interpreter is not available or feasible.

## Narrative synthesis

This is an acceptability claim grounded in staff self-report (usefulness ratings, future-use intention, and reported usage for everyday low-risk tasks), not an effectiveness claim. The study did not directly capture patients' perceptions.
